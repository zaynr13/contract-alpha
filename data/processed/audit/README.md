# Aggregate audit outputs

Generated by:

```bash
PYTHONPATH=src python3 scripts/run_data_audit.py
```

Files:

- `audit_summary.json`: machine-readable headline counts, percentages, distributions, sources, timestamp, and a checksum over the summary payload.
- `tracker_coverage_by_season.csv`: tracker, signing, complete-terms, threshold, WAR, projection, and crowd counts by signing class.
- `performance_coverage_by_season.csv`: pre/post leaderboard-row coverage for complete 2020–2025 contracts.
- `missingness_signed_rows.csv`: missingness across every tracker row with a signing team.
- `role_split_complete_contracts.csv`: hitter, pitcher, and two-way split for complete 2020–2025 contracts.
- `age_distribution_completed_classes.csv`: prespecified age bands.
- `contract_value_distribution_completed_classes.csv`: nominal guarantee bands.
- `eligibility_sensitivity.csv`: sample size, duplicate groups, and coverage under alternative guarantee screens.

These are aggregate audit artifacts, not the Phase 2 row-level research dataset. Source HTML and row-level extracts are not committed pending source-license and redistribution review.
